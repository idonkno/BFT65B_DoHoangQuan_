At 100x, pandas needs ~112 GB working set -> >= 3 executors of 64 GB (60% usable) if distributed.
At 100x, polars needs ~68 GB working set -> >= 2 executors of 64 GB (60% usable) if distributed.

DECISION RULE: single-machine Pandas/Polars is sufficient up to ~11x (~19 M rows). Beyond that (or when the working set > 80% RAM, or a job must finish within an SLA that 1 node cannot meet), a Spark cluster is justified.
At 10x (16.8M rows) the workload still fits a laptop; at 100x (168M rows) it does not.
